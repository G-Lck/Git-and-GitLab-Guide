# Git and GitLab Course

This repository contains a guide to the basics of Git and GitLab.

It includes the course exercises and presentations.

The guide is also published as a static web page through GitHub Pages. After enabling Pages in **Settings > Pages** with **GitHub Actions** as the source, each push to the `main` branch deploys the page to the URL shown there.
