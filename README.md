# Git and GitLab Course

This repository contains a guide to the basics of Git and GitLab.

It includes the course exercises and presentations.

The guide is also published as a static web page through GitHub Pages. After pushing to the `main` branch, the page will be available at the URL shown under **Settings > Pages** in GitHub.
